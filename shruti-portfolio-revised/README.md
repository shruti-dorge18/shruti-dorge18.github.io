# Shruti Dorge — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. The styling follows the supplied reference, with a warm white default theme, dark-mode toggle, animated introduction, social links, writings, and project cards.

## Files

- `index.html` — page content and structure
- `styles.css` — layout, colors, typography, responsive styles, and dark theme
- `script.js` — theme toggle, animated intro text, and Mumbai local time

## Run locally

Open `index.html` in a browser. No build tools or package installation are required.
